## 🎯 5 Pertanyaan Wawancara Paling Sering Muncul & Contekkan Jawabannya

### 1. Pertanyaan: "Coba ceritakan tentang diri kamu secara singkat."
* **Tujuan Pewawancara:** Ingin tahu latar belakang pendidikan dan fokus ketertarikanmu.
* **Cara Jawab:**
  > *"Halo Bapak/Ibu, perkenalkan nama saya Galuh Wibowo, Fresh Graduate S1 Sistem Informasi dari Universitas Bina Sarana Informatika (UBSI). Saya memiliki minat mendalam di bidang Frontend Web Development. Selama kuliah dan magang berbasis proyek, saya terbiasa membangun antarmuka web yang rapi dan responsif menggunakan HTML, CSS, dan JavaScript murni. Saya juga memiliki sertifikasi kompetensi Analis Program dari BNSP RI. Saat ini saya sangat bersemangat untuk memulai karier profesional dan berkontribusi langsung sebagai Frontend Developer Intern di perusahaan ini."*

---

### 2. Pertanyaan: "Bisa ceritakan proyek Brain IPA yang ada di portofolio kamu?"
* **Tujuan Pewawancara:** Menguji apakah proyek itu benar-benar kamu yang buat dan paham alurnya.
* **Cara Jawab:**
  > *"Brain IPA adalah aplikasi web edukasi interaktif untuk mengenalkan sistem organ tubuh manusia (seperti jantung, paru-paru, lambung, dan ginjal) kepada siswa SMP.*  
  > *Di proyek ini, saya menggunakan HTML5 semantik, CSS3 modern untuk animasi dan tampilan responsif, serta JavaScript murni untuk menangani interaksi pengguna. Ketika pengguna mengklik organ tertentu, sistem akan secara dinamis mengganti visual organ, memutar audio edukasi, dan menampilkan penjelasan medisnya tanpa perlu me-reload halaman."*

---

### 3. Pertanyaan: "Sejauh mana pemahaman JavaScript kamu saat ini?"
* **Tujuan Pewawancara:** Mengukur level teknis kamu tanpa harus menguji hal yang terlalu rumit.
* **Cara Jawab (Jujur & Berbobot):**
  > *"Secara fundamental, saya sudah menguasai logika pemrograman dasar seperti variabel (let/const), struktur kondisi (if/else), perulangan, fungsi, serta manipulasi data Array dan Object. Saat ini saya juga sedang aktif mendalami pemrograman Asynchronous seperti Promise dan Fetch API untuk menghubungkan web dengan data dari server/backend."*

---

### 4. Pertanyaan: "Bagaimana cara kamu memastikan tampilan web tetap rapi saat dibuka di layar HP (Mobile)?"
* **Tujuan Pewawancara:** Memastikan kamu paham konsep dasar Responsive Design.
* **Cara Jawab:**
  > *"Saya menerapkan prinsip Responsive Web Design dengan memanfaatkan fitur modern CSS, yaitu CSS Flexbox dan CSS Grid untuk tata letak yang fleksibel. Selain itu, saya menggunakan CSS Media Query (`@media screen`) untuk mengatur ukuran font, tombol, dan susunan elemen agar otomatis menyesuaikan dengan resolusi layar smartphone pengguna."*

---

### 5. Pertanyaan: "Di sini nanti ada proyek menggunakan React / teknologi baru lainnya, apakah kamu siap?"
* **Tujuan Pewawancara:** Menguji fleksibilitas dan antusiasme belajar kamu.
* **Cara Jawab (Jawaban Emas ⭐):**
  > *"Sangat siap, Bapak/Ibu! Karena fondasi HTML, CSS, dan logika dasar JavaScript saya sudah terbangun, saya sangat percaya diri bisa mempelajari library atau framework baru seperti React dengan cepat di bawah bimbingan tim senior di kantor."*

---

### 6. Pertanyaan: "Apakah dalam pembuatan proyek/coding kamu dibantu oleh AI?" (Vibe Coding / AI Assistant)
* **PENTING:** Jangan takut atau malu mengaku pakai AI! Ingat di deskripsi lowongan PT Qtera Mandiri mereka secara eksplisit mencari kandidat yang:  
  👉 *"Memiliki kemauan belajar yang tinggi dan terbiasa memanfaatkan AI tools (seperti ChatGPT, GitHub Copilot, Cursor) untuk mendukung proses pengembangan."*
* **Trik Jawaban Cerdas (Jadikan Kekuatan, Bukan Kelemahan):**
  > *"Iya betul Bapak/Ibu, dalam proses pengembangannya saya memanfaatkan AI tools sebagai asisten dan rekan diskusi (pair programmer).*  
  > *Biasanya saya gunakan AI untuk membantu brainstorming struktur logika, mencari solusi ketika ada bug atau error, dan mengeksplorasi cara penulisan kode yang lebih efisien.*  
  > *Namun, saya selalu memastikan untuk membaca, memahami, dan menguji sendiri alur kodenya agar saya benar-benar mengerti cara kerja fitur tersebut di web saya.*  
  > *Menurut saya, pemanfaatan AI justru sangat membantu mempercepat proses belajar dan meningkatkan produktivitas saya dalam menyelesaikan masalah pemrograman."*
