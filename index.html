Brain IPA – Media Pembelajaran Interaktif Sistem Organ Manusia

Membangun aplikasi web media pembelajaran mandiri untuk siswa SMP Kelas VIII. Memadukan 5 modul materi biologi, visualisasi diagram interaktif, 5 mini games, dan 10 kuis pilihan ganda dengan engine JavaScript murni (3.900+ baris kode) tanpa ketergantungan framework pihak ketiga.

Materi sistem organ manusia (seperti sirkulasi darah ganda dan filtrasi nefron ginjal) bersifat abstrak dan sulit divisualisasikan dari buku teks statis. Proyek ini bertujuan menyediakan sarana belajar visual, interaktif, dan berbobot ringan yang dapat dibuka instan di smartphone siswa.

  • Clean Architecture: Menulis 3.900+ baris JavaScript murni dengan router multi-halaman mandiri.
  • Web Audio API: Efek suara interaktif untuk responsivitas kuis dan dinamika game edukatif.
  • Resource Preloading: Transisi halaman 0ms dan splashscreen dinamis tanpa jeda waktu muat.
  • Mobile-First & Dark Mode: Desain adaptif ramah sentuhan dengan sistem tema terintegrasi.
  • Performa Instan: First Contentful Paint < 0.8 detik dengan skor Lighthouse 98/100.
  • Frame Rate Stabil: Berjalan mulus di 60 FPS pada beragam tipe perangkat mobile siswa.
  • Retensi Pembelajaran: Meningkatkan antusiasme dan pemahaman materi biologi melalui gamifikasi.

E-Commerce Product Catalog – Dynamic Theming & REST API

Aplikasi Single Page Application (SPA) katalog produk interaktif berbasis Vue.js dan Vite. Mengonsumsi data katalog FakeStore REST API secara asinkron dengan fitur pengubah tema visual dinamis otomatis berdasarkan kategori busana (*Men's Clothing* & *Women's Clothing*) serta penanganan status produk yang tidak tersedia.

Membangun antarmuka katalog belanja yang adaptif terhadap variasi kategori produk dari REST API publik. Tantangan utamanya adalah mengotomatisasi perubahan skema warna (*color palette*) seluruh aplikasi tanpa kedipan visual, mengelola siklus pemuatan data (*loading state*), serta menangani fallback produk di luar kategori busana tanpa membuat aplikasi crash.

  • Dynamic CSS Variables Theming: Memanfaatkan computed properties Vue untuk memetakan kategori produk ke tema warna biru (pria), ungu (wanita), dan abu-abu (unavailable).
  • Robust Asynchronous Fetching: Penanganan pemanggilan API dengan blok try-catch-finally untuk loading spinner dan verifikasi validitas kategori produk.
  • Custom Rating Circles: Mengembangkan indikator rating 5 lingkaran berbasis data rating dinamis FakeStore.
  • Modular Component Architecture: Kode terstruktur rapi yang siap di-scale dengan bundling modern Vite.
  • Zero Layout Shifts (CLS 0): Transisi tema dan perpindahan produk terasa instan dan responsif.
  • Spesifikasi VIX Terpenuhi 100%: Memenuhi seluruh acceptance criteria program frontend developer virtual internship.
  • Production-Ready Build: Optimalisasi asset production dengan minifikasi dan performa tinggi.
